# 그림·목소리 바꾸는 법

## 그림
- 이 폴더(assets)의 그림 파일을 **같은 이름으로 덮어쓰면** 게임 그림이 바뀝니다.
  - 손님: cust/bear.svg(곰), cust/rabbit.svg(토끼), cust/squirrel.svg(다람쥐)
  - 사장님: owner.svg
  - 메뉴: item/americano.svg, latte, milk, juice, cookie, candy, muffin, cake
- PNG 그림을 쓰려면 manifest.json 에서 해당 줄의 파일 이름만 .png 로 바꾸면 됩니다.
- 파일이 없거나 열리지 않으면 게임 안에 들어 있는 기본 그림이 나옵니다.

## 목소리
- 녹음 파일(mp3 등)을 voice 폴더에 넣고, voice/voice.json 에 "대사": "파일이름" 을 적으면
  그 대사는 녹음 파일로 나옵니다. 적혀 있지 않은 대사는 기기 목소리로 나옵니다.
  예: { "가게 문을 열었어요! 첫 손님이 와요.": "open_shop.mp3" }
